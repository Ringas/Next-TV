Next TV — 开源项目与第三方组件

本应用（Next TV）按 GNU GPL v3（GPL-3.0-only）分发；完整条款见随包 LICENSE。

交付安装包附对应可构建源码；签名私钥、本机工具链、用户订阅及频道缓存不属于公开源码交付内容。

主要运行组件（版本以对应源码 Gradle 配置及解析依赖为准）：
• AndroidX Compose / Compose for TV、Activity、Lifecycle、ProfileInstaller：Apache-2.0。
• AndroidX Media3 / ExoPlayer 1.9.4：Apache-2.0；视频通常通过 Android MediaCodec 解码。
• Kotlin 与 kotlinx.coroutines：Apache-2.0。
• ZXing Core 3.5.3：Apache-2.0，用于二维码生成。
• JLayer（com.googlecode.soundlibs:jlayer:1.0.1.4）：LGPL-2.1，提供 MP2 音频解码补充。
• desugar_jdk_libs：GPL-2.0 with Classpath Exception，用于旧版 Android 的 Java API 兼容。
各组件版权属于其原作者；其许可不被本项目的 GPL 声明取代。

未接入 IJK、VLC 等其他播放内核。自动／硬件／软件为当前播放栈的解码选择，
不代表内置多种独立播放引擎。系统解码器能力取决于设备。
